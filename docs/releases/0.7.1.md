### Consistent controls and spacing

Penguin Studio 0.7.1 harmonizes control heights, padding, corner radii and selected states across the production toolbar, Inspector, settings, source dialogs and native chat. Split-menu actions reserve a separate, centered arrow area, keeping their labels clear. Icon-only actions use balanced square hit areas and the application-menu arrow is vertically centered.

Buttons use symmetric padding and centered captions. Form controls can grow with larger text; tabs use a consistent underline and retain a visible keyboard-focus state. Chat uses the shared theme instead of overriding input and button sizes locally. Stream-detail labels remain readable in narrow docks.

Long camera-background options no longer force the Inspector wider than its viewport, and the Processing label hides with its control when automatic processing is inactive. Recording, camera processing and platform authentication behavior are unchanged.

All seven Linux package targets passed their candidate workflow. Native Wayland tests passed 242 workspace checks in both Ubuntu and Flatpak, 18 Ubuntu dialog captures at enlarged text, camera pixel/Inspector checks, native chat layout checks and startup/shutdown scenarios. The Ubuntu GPU recording fully decoded with no reported render-lag or encoder-skip events. See the [validation record](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/validation/design-consistency-0.7.1.md) for scope and known environment diagnostics.
