# Penguin Studio 0.7.6

Connect Twitch or YouTube directly on the auto-configuration wizard's Stream Information page. **Use Stream Key** remains an optional alternative. After browser authorization, **Use this account** supplies streaming access without copying a key. Changing services clears the previous wizard credentials; closing setup does not start a broadcast.

Twitch accounts authorized previously may need **Reconnect** to grant stream-key access. YouTube requires an existing encoder broadcast with a configured, bound stream in YouTube Studio. This setup does not create or start broadcasts. The YouTube bandwidth test is disabled after account setup to avoid sending test video to that broadcast.

Integrated chat now rejects interrupted or malformed successful responses. YouTube reload recovers when an expired access token is replaced, and the reload menu follows the selected original-website or integrated-chat mode. Unconfirmed sends are not automatically retried.

## Validation and limits

Reviewed local builds passed provider fixtures and ASan/UBSan, 16 real-wizard assertions, 237 Wayland workspace assertions, 35 synthetic recording/local-RTMP assertions and eight preview/WebEngine assertions. Recordings fully decoded and final test sessions closed cleanly with zero reported OBS memory leaks. Provider replies were simulated; these checks do not claim real-account consent, moderation or live-provider streaming coverage.
