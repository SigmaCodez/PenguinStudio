# Penguin Studio 0.7.3

This development release improves platform chat and stream metadata while retaining the classic Penguin Studio workspace.

- Original Twitch and YouTube chat views in packages with Qt WebEngine; integrated API chat remains available. Flatpak currently uses integrated chat.
- Automatic stream-detail loading with protection for unsaved edits.
- YouTube broadcast selection is remembered, shows the video ID, prefers ongoing broadcasts when no selection can be restored, and drives both chat views consistently.
- Explicit guidance when Google website sign-in opens the external browser; integrated YouTube chat uses the existing account connection.
- Moderation validates actions and targets, updates confirmed Twitch deletions immediately, preserves state on failed unbans and explains quota, permission and conflict errors.
- Redundant settings, details and dashboard shortcuts removed without removing access to the underlying features.

## Validation

Local Wayland testing passed 237 workspace checks, chat/account-flow regressions, recording and loopback streaming tests, and clean shutdown. Integrated YouTube sending and individual-message deletion were confirmed against the browser. Timeout/ban/unban behavior was tested with simulated responses only; no real test accounts were available. Google embedded website sign-in and arbitrary account eligibility are not guaranteed.

## Linux downloads

Ubuntu 26.04/26.04.1 and 26.10 DEBs, Fedora 44 RPM, Flatpak, Snap core26, AppImage, Arch/AUR recipe and optional AMD camera runtime DEBs are built by GitHub Actions. Use the package for your distribution. AppImage requires glibc 2.43 or newer. The Arch recipe is downloadable; no AUR listing is published.

The optional AMD runtime enables tested GPU matting on the RX 9070 XT; unsupported combinations retain CPU fallback. Stop recordings and streams before updating. Website chat may require a separate sign-in. See [chat behavior and limits](../CHAT.md) and [installation](../PACKAGING.md).
