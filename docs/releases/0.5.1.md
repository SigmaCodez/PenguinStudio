### Camera improvements

- Automatic background removal now uses the bundled obs-backgroundremoval RVM implementation, accepted in a real Facecam movement test under Wayland.
- Matting works together with rectangle, circle, oval and rounded-corner camera shapes.
- Managed filter pairs preserve their order and settings across Undo/Redo and restarts. Filter changes are synchronized with rendering.
- USB cameras receive a bounded first-frame startup grace period; later capture failures still produce diagnostics.
- Upstream plugin, model and library attribution and license notices are included in the packages.

For existing scenes, switch background removal off and back to Automatic in the Inspector to select the new implementation. Check the live preview before recording; matting quality still depends on motion, lighting and the scene.
