### Optional moving-hand preservation

Penguin Studio 0.6.2 adds **Preserve moving hands** to the camera inspector for automatic background removal, background blur and custom background images. It combines RVM with a local body-skin model and waits for both results from the same frame. Rounded corners and other camera shapes remain available. The option is off by default, is saved with the source and participates in undo/redo. English and all seven Penguin UI translations include the new control.

### Validation and known limits

In the pre-release prototype’s real Elgato Facecam 4K movement test under Wayland, both hands remained identifiable and the tester confirmed fluid motion. The complete recording decoded successfully and the app closed without warning/error diagnostics or reported memory leaks. The 70-second motion run nevertheless logged **one render-lag frame and one encoder-skipped frame**. A subsequent control reported zero, but sampled frames contained no person; it does not establish zero-loss motion performance. Fast edges can remain soft, and the model can retain unwanted skin-like regions. The option needs additional CPU capacity; test recording statistics before broadcasting and disable it if performance worsens.

The Ubuntu 26.04 candidate package passed native Wayland camera GUI checks, including the new checkbox and restored settings. A 40.021-second replay of the private movement reference decoded fully with no reported frame-loss events and clean shutdown. This is a replay result, not a new zero-loss live-camera claim. See [package validation](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/validation/hand-preservation-0.6.2.md).

Private camera footage is not distributed. See the [camera guide](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/CAMERA-EFFECTS.md) for usage and the [test evidence](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/experiments/hand-preservation/results.json) for the measured counters.
