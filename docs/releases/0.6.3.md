### Security and reliability maintenance

Penguin Studio 0.6.3 hardens media and RTMP packet parsing, bounds nested AMF decoding, and updates the embedded browser to OBS Browser 2.27.4 with CEF 7871. It includes upstream corrections for audio/video task deadlocks, ALSA device shutdown and duplicate PipeWire captures in Studio Mode. Author and license notices are preserved.

### Camera GPU processing

Automatic/GPU/CPU preferences keep camera effects available with automatic CPU
fallback. GPU initialization runs in an isolated helper so slow compilation or a
driver failure cannot block initialization of the main window. Primary RVM runs
on the GPU; hand preservation remains on CPU after direct mask comparisons found
incorrect contours from the current AMD hand-model graph. The confirmed RX 9070
XT Facecam movement test under Wayland completed 1,504 recording frames without
reported rendering/encoding losses, with a fully readable file and clean exit.
This is measured evidence for that configuration, not a zero-loss guarantee.

An optional Ubuntu 26.04 gfx1201 runtime add-on accompanies the regular downloads.
It does not replace system drivers. Other packages retain CPU fallback; see the
package guide for scope and installation.

### Validation

All eight Linux download artifacts passed [candidate build 40201246032](https://github.com/SigmaCodez/PenguinStudio/actions/runs/40201246032). The Ubuntu 26.04 package passed native Wayland camera/Inspector checks, 211 workspace checks, nine shutdown scenarios, local horizontal/vertical RTMP tests, saved Twitch/YouTube sessions and category searches, and the GitHub update check. The package's 1,498-frame GPU reference recording kept GPU processing active, reported no rendering/encoding losses, decoded fully and exited cleanly. A separate 1,501-frame CPU reference recording also decoded without reported frame-loss events. Current English previews use this real package with synthetic local media.

The short workspace smoke recording reported two render-lag frames; zero-loss performance is not universal. A sporadic Qt Wayland text-input focus warning was observed when opening the updater, including a restart test. Delayed opening and the dedicated focus/close scenario passed, but this warning is not considered fully resolved; release queries and normal shutdown still succeeded. Full provider broadcasts and all hardware/distribution combinations remain outside this test scope. Private webcam recordings and account data are not published. No claim of complete security or perfect segmentation is made.
