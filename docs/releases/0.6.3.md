### Security and reliability maintenance

Penguin Studio 0.6.3 hardens media and RTMP packet parsing, bounds nested AMF decoding, and updates the embedded browser to OBS Browser 2.27.4 with CEF 7871. It includes upstream corrections for audio/video task deadlocks, ALSA device shutdown and duplicate PipeWire captures in Studio Mode. Author and license notices are preserved.

### Validation

All Linux package builds passed. The Ubuntu candidate passed 211 workspace checks, synthetic camera effects, nine shutdown scenarios, local horizontal/vertical RTMP tests, Twitch session restoration and the GitHub update check. Current English GUI previews have been captured and reviewed. Real YouTube authorization and Facecam movement validation are still pending; this version is not yet published. No claim of complete security or universally zero dropped frames is made.
