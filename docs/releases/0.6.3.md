### Security and reliability maintenance

Penguin Studio 0.6.3 hardens media and RTMP packet parsing, bounds nested AMF decoding, and updates the embedded browser to OBS Browser 2.27.4 with CEF 7871. It includes upstream corrections for audio/video task deadlocks, ALSA device shutdown and duplicate PipeWire captures in Studio Mode. Author and license notices are preserved.

### Camera GPU processing

Automatic/GPU/CPU preferences keep camera effects available with automatic CPU
fallback. GPU initialization runs in an isolated helper so slow compilation or a
driver failure cannot block initialization of the main window. Primary RVM runs
on the GPU; hand preservation remains on CPU after direct mask comparisons found
incorrect contours from the current AMD hand-model graph. The confirmed RX 9070
XT Facecam movement test under Wayland completed 1,504 recording frames without
reported rendering/encoding losses, with a fully readable file and clean exit.
This is measured evidence for that configuration, not a zero-loss guarantee.

An optional Ubuntu 26.04 gfx1201 runtime add-on accompanies the regular downloads.
It does not replace system drivers. Other packages retain CPU fallback; see the
package guide for scope and installation.

### Validation

All Linux package builds passed before an additional updater-dialog focus correction; replacement builds are required. The Ubuntu candidate passed 211 workspace checks, synthetic camera effects, nine shutdown scenarios, local horizontal/vertical RTMP tests, Twitch session restoration and the GitHub update check. Current English GUI previews have been captured and reviewed. Real YouTube authorization, categories and saved-session restoration passed. A Facecam recording exposed isolated false skin detections in optional hand recovery; a targeted correction passed synthetic tests and a same-input replay, with live acceptance and final package validation still pending. This version is not yet published. No claim of complete security or universally zero dropped frames is made.
