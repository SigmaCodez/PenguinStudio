# Penguin Studio 0.7.7

Twitch and YouTube sign-in now supplies streaming access to **Broadcast destinations**. Previously, account setup configured the primary stream but the Outputs dock still asked for a separate stream key.

- Existing and new account-based destinations reuse the selected platform account. Their editor hides the manual key field while account mode is selected.
- Reconnecting or selecting another YouTube broadcast updates inactive account destinations. Disconnect clears their session credentials. Running outputs retain their configuration until stopped.
- Manual stream-key setup remains available and manual destinations are not overwritten by account updates.
- Destination files save the selected account/manual mode and non-secret settings, never streaming keys. Restored account sessions resolve streaming access again after launch.
- Signing in does not start an output. YouTube still requires an existing encoder broadcast with a configured bound stream; older Twitch grants may require reconnecting for stream-key access.
