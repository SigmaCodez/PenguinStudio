# Penguin Studio 0.7.2

## Changes

- A simpler Qt Quick workspace groups source editing, streaming channels, title/category and live chat. Searchable navigation and settings retain visible keyboard focus.
- A redesigned status bar hides inactive output timers and groups recording, CPU, GPU and frame-rate information. Supported Linux drivers report utilization of the rendering GPU; unavailable counters show a dash instead of a misleading zero.
- Check for updates directly from Settings, with automatic checks at startup. Native update selection now includes Ubuntu 26.10.
- Camera inference and hand recovery run outside the rendering thread with one bounded task. Color and mask frames stay paired, and GPU failures retain CPU fallback.
- Rust camera preprocessing and reduced image-file polling carry the locally reviewed optimizations into Linux packages.
- An additional native Ubuntu 26.10 DEB and matching optional AMD camera-runtime add-on complement the Ubuntu 26.04 packages.

## Validation

Native Ubuntu 26.04 and 26.10 package installation and camera pixel checks passed in CI. The actual Ubuntu packages also passed 90-second Wayland recordings with full decode, no reported render/encoder losses and clean shutdown. The Ubuntu 26.04 package passed 232 workspace assertions and the Settings update-check flow. AppImage passed the same workspace checks and camera pixel checks under Wayland. All Linux package builds passed in candidate CI run 40428246369; the Flatpak runtime check is the remaining pre-publication gate.

The private five-minute Facecam candidate test on an AMD RX 9070 XT decoded 9,003 video frames without reported render or encoder losses and exited cleanly. Five late inference ticks reused the previous complete color/mask pair. This is not a claim that every captured camera frame was processed, nor a guarantee for other hardware. Private recordings are not distributed.

Ubuntu 26.10 runtime checks used an isolated 26.10 userspace with the Ubuntu 26.04 host kernel and Wayland compositor. This is not a separately booted 26.10 desktop certification. Camera inference may reuse the previous complete frame while busy; zero reported render/encoder losses does not mean every camera frame underwent inference. See [the validation record](../validation/workspace-camera-0.7.2.md) for exact scope and limitations.
