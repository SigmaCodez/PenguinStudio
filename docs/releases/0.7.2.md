# Penguin Studio 0.7.2

Creator tools, measured upload bitrate, the classic workspace, smoother camera processing and Ubuntu 26.10 packages.

## What changed

- **Creator tools:** an advisory stream check for program sources, storage, stream configuration and audio routing; separate explanations for rendering, encoding, network and output errors.
- **Recording helpers:** live recording state, approximate video duration and written-data counters; container resilience advice and a manually copied diagnostic snapshot that excludes account details, paths and credentials.
- **Upload bitrate:** a bottom-right measured total for the primary stream and Penguin multistream destinations. Sampling uses per-output byte counters and elapsed time; the monitor sleeps when no streams are active or starting.
- **Audio assistant:** measure voice levels locally, review a suggested fader level, optionally add noise suppression, and apply compression/limiting without duplicating existing filters. Undo preserves later manual volume changes. No audio is uploaded.
- **Privacy:** a persistent top-bar control masks the program picture and silences source audio while outputs continue. Scene/transition changes and newly created regular audio sources remain covered. The local editing preview can remain visible; independently implemented third-party outputs are outside its scope.
- Retain the classic Penguin Studio workspace, native menus, settings and charcoal theme. Privacy shares the production controls' layout and icon system, while Creator tools uses consistent cards, compact actions and status badges. The experimental Qt Quick navigation is not shipped.
- A compact status bar groups recording, CPU, supported GPU utilization and frame-rate information. Unavailable GPU counters display a dash.
- Manual update checks in Settings, automatic checks at startup, and native Ubuntu 26.10 update selection.
- Asynchronous camera inference/model preparation, bounded processing, paired color/mask frames, CPU fallback, cached blur rendering and Rust preprocessing reduce avoidable rendering work.
- Native Ubuntu 26.10 DEB and matching optional AMD camera runtime, alongside Ubuntu 26.04 packages.

## Validation and limits

Local checks covered the installed Ubuntu 26.04 build under Wayland: 210 existing workspace assertions, 31 Creator tools/upload integration assertions, simultaneous loopback streaming and recording, CPU/GPU camera recordings, full recording decode, privacy across scene and transition changes, audio undo, restart cleanup and clean shutdown. No frame-loss events were reported in those recordings. GPU processing used the RX 9070 XT runtime without CPU fallback. Audio guard and error-classification checks passed memory and undefined-behavior sanitizers.

The creator tests used synthetic pictures and tones. Stream preflight does not validate provider authorization or upload bandwidth; real microphone tuning and physical keyboard interaction still need user review. Privacy cannot recall already transmitted or buffered frames. Hardware and provider behavior varies; these checks do not guarantee zero frame loss in every workload.
