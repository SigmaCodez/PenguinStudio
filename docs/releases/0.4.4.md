# Penguin Studio 0.4.4

This maintenance release fixes the AAC queue warning when a recording stops.
FFmpeg audio encoders now finish draining delayed packets before their stopped
contexts are freed. Output stop timestamps and existing recordings are unchanged;
the application does not suppress the warning through a log filter.

## Regression checks

Real FFmpeg AAC tests cover empty, single-frame and longer sessions, pending
packets, repeated cleanup and PCM compatibility. Local sanitizer checks passed.
On Ubuntu 26.04.1 under native Wayland, three successive AMD VA-API/AAC
recordings fully decoded, stopped without warnings and retained valid audio.
Application close and restart/close tests also passed with no warnings/errors
and zero reported memory leaks. See [verification results](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/VERIFICATION.md)
for native Wayland and installed-package results.

## Linux downloads

Use the assets below for Ubuntu 24.04, Ubuntu 26.04 / 26.04.1, Fedora 44,
Flatpak, Snap, AppImage and the Arch packaging recipe. Verify the selected file
against `SHA256SUMS`; `build-manifest.json` records its source and hash.

See the [installation guide](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/PACKAGING.md)
and [AppImage/Arch instructions](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/APPIMAGE-AUR.md).
The Arch recipe remains a GitHub download; no AUR account or listing has been created.

Original author credits and licenses are retained. This remains a development
preview; tests on one Ubuntu/AMD system do not establish compatibility with every
GPU or distribution desktop.
