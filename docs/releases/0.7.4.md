# Penguin Studio 0.7.4

This development release adds practical recording helpers while keeping the classic Penguin Studio workspace.

- Fix a black native Wayland preview when an embedded browser/chat recreates the window surface. The preview now restores its rendering surface after Qt replaces it.
- Add named chapter marks while recording to a compatible container, such as Hybrid MP4. Unsupported outputs show a clear explanation.
- Keep format-independent highlight notes with approximate video timestamps and export them as UTF-8 text. Pauses keep their video timestamp; separate recordings retain separate identities. Export notes before quitting: notes are held only for the current app session.
- Recording storage checks now follow custom FFmpeg file paths and require an existing writable directory. Replay readiness and an active privacy shield are made explicit in Stream check.
- Every normal Linux startup checks for updates in the background. Only a newer eligible release opens a notification; up-to-date and failed background checks remain silent. Update notifications wait until outputs and modal dialogs have finished. The manual update command remains available.

## Validation and limits

The reviewed local changes passed 237 Wayland workspace checks, 35 loopback-stream/recording checks and 34 highlight-note/chapter checks. Completed recordings were decoded, chapter metadata inspected, and recording pause/restart and text export tested. Local installation checks passed. All nine Linux downloads passed hash and size verification. The final Ubuntu DEB passed 237 workspace checks, 35 recording/local-stream checks and eight native preview/WebEngine checks under Wayland; recordings fully decoded and all three test sessions exited normally with zero OBS memory leaks. See the [final package evidence](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/validation/release-0.7.4.md).

Notes are not uploaded, included in diagnostics or embedded in the video. Timestamps are approximate; split files may reset counters. Chapter support depends on the output and editor. The file-dialog test recorded a Glycin sandbox diagnostic; no security setting was disabled to hide it. This release does not claim new real-account ban/timeout or all-device validation.

## Linux downloads

Ubuntu 26.04/26.04.1 and 26.10 DEBs, Fedora 44 RPM, Flatpak, Snap core26, AppImage, the Arch recipe and optional AMD camera-runtime DEBs are built by GitHub Actions. AppImage requires glibc 2.43 or newer. The Arch archive is a downloadable recipe, not an AUR listing. Flatpak currently provides integrated API chat rather than the Qt WebEngine original chat view.
