# Penguin Studio 0.7.5

This update makes integrated chat more efficient and reliable while preserving the classic workspace.

- Twitch retains unchanged message rows instead of recreating the entire list. Selection and the visible reading position survive incoming messages and history trimming; moderation removes only affected rows.
- Reloading integrated YouTube chat cancels obsolete requests, pauses send until the new chat is ready and prevents overlapping message polls.
- Bounded message-ID indices speed up YouTube duplicate detection while retaining the existing history limits and deletion replay protection.
- Disconnect cancels only each view's own network requests. Delayed Twitch send-button updates cannot change a later account session.

## Validation and limits

Both reviewed local builds passed the combined Twitch/YouTube fixture, simulated sign-in/refresh/callback tests, address/undefined-behavior sanitizer checks, 237 Wayland workspace checks and 35 recording/local-loopback checks. Recordings fully decoded and installed local builds exited normally with zero OBS memory leaks.

Local synthetic timings improved from 37 to 7 ms for 2,500 YouTube messages plus 500 duplicates, and from 358 to 5 ms for 100 Twitch updates of 500 retained rows. These are narrow local measurements, not promises of whole-app CPU/GPU reduction or live-platform throughput. Real-account timeout/ban/unban tests were not performed.

These improvements apply to integrated API chat. Original Twitch/YouTube website views remain separate; Google browser sign-in does not authenticate an embedded website session. Flatpak currently provides integrated chat without Qt WebEngine. All existing recording, camera and startup update-check features remain.

## Linux downloads

Ubuntu 26.04/26.04.1 and 26.10 DEBs, Fedora 44 RPM, Flatpak, Snap core26, AppImage, the Arch recipe and optional AMD gfx1201 camera-runtime DEBs are built by GitHub Actions. AppImage requires glibc 2.43 or newer. The Arch archive is a recipe, not an AUR listing.
