# Penguin Studio 0.4.2

Automatic hardware encoding for your Linux studio. This development preview includes all five Linux packages.

## New in 0.4.2

- Automatically select available NVIDIA NVENC or Linux VA-API H.264 encoders for new simple-output profiles, the setup assistant and new multistream destinations.
- Check VA-API CBR/CQP support and fall back to software encoding when unavailable. Existing explicit encoder choices are preserved.
- Include NVENC in all Linux package builds and recommend Mesa VA drivers for Ubuntu.

## Included features

- A redesigned production workspace, source inspector and native Twitch chat dock.
- Browser sign-in for Twitch and YouTube using the application configuration included in official packages; no user-entered client IDs required.
- Searchable Twitch games and YouTube video categories, with saved sign-ins restored from the system keyring.
- Optional account sign-in during first setup, landscape/portrait multistream output and verified in-app updates on supported Ubuntu, Fedora and Flatpak installations.

## Verified for this release

All five Linux builds and their automated checks passed. On Ubuntu 26.04.1 with an AMD Radeon RX 9070 XT, native Wayland hardware selection, recording, simultaneous landscape/portrait loopback output, restart and shutdown passed. The installed application logged no warnings or errors in the final startup/shutdown checks.

NVIDIA hardware was not available for a runtime test. GPU/driver compatibility and cross-distribution GUI testing remain incomplete. Google consent and account eligibility rules still apply. See [verification results](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/VERIFICATION.md) and [hardware setup](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/HARDWARE-ENCODING.md).
