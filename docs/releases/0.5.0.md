# Penguin Studio 0.5.0

## Camera appearance

- Choose Rectangle, Circle, Oval, or Rounded corners directly in the source Inspector.
- Adjust the corner radius and combine shapes with background removal.
- Remove a person's background automatically using local AI, without a green screen.
- Alternatively select Green screen or Blue screen and adjust the key threshold.
- Keep source effects across scene-collection saves, with Inspector Undo/Redo support.
- See local AI preparation and error status directly in the Inspector.

The segmentation model and CPU runtime are included in the Linux packages. No
camera images are uploaded and no model download is required. Automatic portrait
segmentation can lose detail around hair, transparent items and unusual lighting.

English defaults and German, French, Spanish, Brazilian Portuguese, Italian,
Japanese and Simplified Chinese translations are included for the new controls.

## Downloads

The release workflow builds Ubuntu 24.04 and 26.04 DEBs, Fedora 44 RPM, Flatpak,
Snap, AppImage, and an Arch binary package/recipe. The Arch recipe does not require
an AUR account and is not published to the AUR. Use the package matching your system.

## Checks

The native package build runs model inference checks. The Ubuntu jobs also test
the Inspector, source persistence, GPU-rendered shapes and both chroma keys before
uploading packages. Local Wayland tests additionally exercise portrait removal and
normal shutdown using an isolated profile and a test image.
