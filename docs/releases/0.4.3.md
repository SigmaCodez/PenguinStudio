# Penguin Studio 0.4.3

New portable Linux downloads: an x86_64 AppImage and a checksum-pinned Arch Linux recipe, alongside the existing Ubuntu, Fedora, Flatpak and Snap packages.

## Changes

- Bundle Qt Wayland platform, shell and graphics integration plugins and the Python 3.12 standard library in the AppImage.
- Use host VA-API libraries to match the installed graphics driver.
- Validate the Arch recipe by building and installing it with makepkg in CI.
- Fix queued thumbnail cleanup on Qt 6.4 by safely capturing the source UUID.
- Generate all six binary packages and the Arch recipe automatically for future version releases.

The Arch recipe is downloadable here but is **not yet listed on aur.archlinux.org**. A maintainer account is required for that separate publication. Follow the [AppImage and Arch installation guide](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/APPIMAGE-AUR.md).

AppImage targets x86_64 hosts with glibc 2.39 or newer; graphics drivers, VA-API and desktop portals remain host-provided. All six package builds and Arch installation checks passed. This remains a development preview; other GPUs and distribution desktops have not all been tested.

Ubuntu DEBs are release-specific; do not install the 24.04 package on 26.04.
The RPM targets Fedora 44. Flatpak requires the Freedesktop 25.08 runtime
from Flathub. Snap requires snapd and local installation with --dangerous;
it is a development build, not a Snap Store publication.
AppImage targets x86_64 hosts with glibc 2.39 or newer. Make it executable and
launch it; `--appimage-extract-and-run` avoids a FUSE dependency. The AUR archive
contains a checksum-pinned `penguin-studio-bin` recipe, not a claim of publication
on aur.archlinux.org. Extract it, review PKGBUILD, then run `makepkg -si` on Arch.
AppImage and Arch installations currently use manual/package-manager updates;
the in-app updater offers release links instead of replacing those installations.

Verify downloaded files with `sha256sum --check SHA256SUMS` after downloading
all listed files, or compare the entry for the package you downloaded.
`build-manifest.json` records the exact source commit and package hashes.

## Local verification

The released Ubuntu 26.04 DEB was installed on Ubuntu 26.04.1. Native Wayland
startup/shutdown passed without warnings or errors. Both the installed package
and extracted release AppImage recorded with AMD VA-API and exited normally with
zero reported leaks. The recording tests still emitted an AAC queue diagnostic;
see the [verification report](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/VERIFICATION.md).
NVIDIA runtime and all distribution desktops remain untested.
