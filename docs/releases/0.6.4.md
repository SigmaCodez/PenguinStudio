### Penguin Studio window title

The main window title and startup banner now show Penguin Studio and its own version, without the inherited OBS version suffix. Profile and scene-collection names remain visible. Author credits, license notices and the About dialog attribution are preserved.

Camera processing, saved streaming accounts, encoders and the updater are unchanged from 0.6.3. The known sporadic Qt Wayland focus warning when opening the updater remains documented; this title-only update does not claim to resolve it.

### Linux downloads

Ubuntu 24.04/26.04 DEBs, Fedora RPM, Flatpak, Snap, AppImage, the downloadable Arch recipe and the optional Ubuntu 26.04 RX 9070 camera runtime are built together. Verify downloads with SHA256SUMS. Penguin Studio remains a development preview.

### Validation

All eight candidate package builds passed in [GitHub Actions](https://github.com/SigmaCodez/PenguinStudio/actions/runs/40208309942). The Ubuntu 26.04 package was opened with isolated English profiles on native Wayland and XWayland. Both reported `Penguin Studio 0.6.4 - Profile: Untitled - Scenes: Untitled`, exited normally without warning/error log entries and reported zero memory leaks. GPU background processing was active in the final preview capture. All three current previews are verified captures of this package using synthetic media.

The broader recording, account-restoration and GPU validation remains documented against [0.6.3](../validation/camera-gpu-0.6.3.md); this release changes the title and startup banner only. An initial preview fixture had a read-only relocated GPU cache and fell back to CPU. Making that test cache writable restored GPU operation without a product code change.
