### Camera recording performance

- Managed automatic background removal now uses up to four physical CPU cores. This reduces inference stalls during recording without changing the RVM model or mask settings.
- Existing managed filters using the original two-thread default migrate once. Explicit non-default choices and independently added filters remain unchanged.
- Real Facecam recordings with automatic background removal and rounded corners passed at 1280×720, 30 fps under Wayland using VAAPI H.264 and AAC. The corrected test recordings decoded completely with no reported rendering/encoding stalls or shutdown diagnostics.

Performance depends on hardware, scene complexity and recording settings. Personal test recordings are not included in this release.
