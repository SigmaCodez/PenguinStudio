### Native chat and camera backgrounds

- Redesigned Twitch and YouTube chat tabs with message cards, role labels and a compact message composer.
- Twitch message deletion, ten-minute timeouts, bans/unbans, chat modes, searchable connected participants and recent chatters.
- YouTube active-broadcast chat, message deletion, timeouts/bans and recent chatters. Bans created in the current session can be removed there.
- Separate live viewer counts where supplied by the platform. Participant lists do not identify all viewers.
- Camera background blur with adjustable strength and custom background images, combined with camera shapes and rounded corners.
- Existing local RVM segmentation, system-keychain sign-in and camera undo/redo are retained.

Reconnect Twitch once to grant the new moderation permissions. YouTube requires
an active broadcast with chat. Native chat does not duplicate every website
feature: the Dashboard button opens the official platform tools for unsupported
features. YouTube polling respects the server interval with a ten-second minimum;
viewer counts update once a minute. Custom background files must remain at their
selected paths.

Automated fixtures exercise moderation requests and responses without sending
messages or moderating real viewers. Camera tests cover blur, image compositing,
rounded corners and restoration. Live moderation against real viewers is not
part of the automated test suite.

The final Ubuntu 26.04 package was installed and checked on Ubuntu 26.04.1 under
native Wayland. Camera controls, both chat tabs and clean shutdown passed without
warnings/errors or reported memory leaks. A synthetic H.264/AAC recording with
blur and custom-image backgrounds decoded fully with zero reported frame drops.
