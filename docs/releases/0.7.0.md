### OBS 33 foundation

Penguin Studio integrates OBS Studio 33.0.0 while retaining its workspace, native Twitch/YouTube docks, camera effects, GPU/CPU processing and Penguin-only window title. The engine update brings upstream improvements to source snapping, numeric controls, plugin loading and recording. Penguin Studio keeps its independent repository history; original authors and licenses remain credited.

Camera image loading now uses the OBS 33 API while preserving transparent-image compositing. Scripting shutdown no longer queries a destroyed frontend. Core modules and private camera resources use the new installation layout. A compatible existing AMD runtime remains usable during a main-package-only update; the matching new add-on is also available.

### Linux compatibility

Native DEBs target Ubuntu 26.04/26.04.1 with FFmpeg 8 and Qt 6.10. The native Ubuntu 24.04 package is discontinued for this engine version. AppImage requires glibc 2.43 or newer. Fedora RPM targets Fedora 44. Flatpak uses Freedesktop 26.08 and Snap uses core26; older hosts need a compatible sandbox runtime. The Arch archive is a downloadable recipe, not an AUR publication.

Qt's new Wayland platform plugin and separately packaged SVG plugins are included in the appropriate package definitions. Third-party plugins must support the OBS 33 ABI and their package's libraries. See the [plugin guide](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/PLUGINS.md) before migrating external plugins.

### Validation

Native Ubuntu Wayland checks cover the workspace, camera controls and pixels, GPU/CPU recording, saved scene migration, ten startup/shutdown scenarios, the updater dialog, offline browser rendering and simultaneous local landscape/portrait output with reconnect. AppImage and Flatpak also passed graphical and camera checks. Test media and profiles were separate from the native personal profile, and the current English previews use only synthetic media.

All seven candidate package targets and their automated checks passed. The packaged AMD migration and missing-runtime CPU fallback also passed 30-second recording/decode and clean-shutdown checks. See the [integration record](https://github.com/SigmaCodez/PenguinStudio/blob/main/docs/validation/obs33-integration.md) for exact source versions, evidence and remaining limits. Live-provider authorization, new Facecam movement acceptance and every third-party plugin are not established by these tests. The host's existing RADV browser diagnostic and absent-AJA-device notices in Flatpak remain documented.
