### OBS 33 foundation

Penguin Studio integrates OBS Studio 33.0.0 while retaining its workspace, native streaming docks, camera effects and application identity. The new core includes upstream improvements to source snapping, numeric controls, plugin loading and recording. Authors and licenses remain preserved.

### Linux compatibility

Native DEBs target Ubuntu 26.04/26.04.1. AppImage requires glibc 2.43 or newer. Flatpak uses Freedesktop 26.08; Snap uses core26. Older hosts should use the compatible Flatpak or Snap runtime rather than the native DEB. The Arch archive remains a downloadable recipe, not an AUR publication.

### Validation status

This is an integration candidate. Full package and Wayland regression testing is pending; this document is not a release approval.
