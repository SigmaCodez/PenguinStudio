# Creator tools local review — 0.7.3 local1

Date: 2026-10-30. Public product version remains 0.7.3. No release or GitHub publication was performed.

## Changes

- Recording storage checks select `AdvOut/FFFilePath` for custom FFmpeg file output, rather than the unrelated standard recording directory. Network-only custom outputs cannot receive a ready local-storage result.
- Storage readiness requires an existing writable directory as well as a ready writable volume and more than 2 GiB available. This is an advisory snapshot, not a write guarantee or forecast.
- Performance help provides optional named recording chapters through the existing frontend API. Unsupported outputs retain the entered name and explain the limitation. Stopped/paused recordings cannot add a chapter; action state is refreshed with the existing timer and rechecked when invoked.
- Stream check distinguishes configured/stopped replay buffering from an active replay buffer and reports an active privacy shield explicitly.
- The initial suspicion that Studio mode inspected the preview was disproved: `obs_frontend_get_current_scene()` already returns the program scene. No scene-selection change was made.
